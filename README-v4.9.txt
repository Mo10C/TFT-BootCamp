=========================================
 v4.9 ― 自己紹介をカテゴリ分け（2026-09-15）
=========================================

■ 画面の構成（上から順に）

 ── 基本 ────────────────────────────
   【名前】               Discordから自動（入力不要）
   【ふりがな】           入力 ★必須
   【呼び方・ニックネーム】入力 ★必須

 ── 🌱 私について ───────────────────
   【趣味】                入力（カンマ区切り）★必須
   【みんなで遊びたいゲーム】入力（カンマ区切り）★必須
   ＋ 自由に足せる項目（最大4つ・見出しも中身も自由）
   ＋ 画像（最大6枚・1枚ずつ一言コメント）

 ── 🏆 TFT ──────────────────────────
   【Riot ID】            ログイン情報から自動（入力不要）
   【Tactics Tool】       URL入力 ★必須
   【合宿での目標】        入力 ★必須
   【意気込み】            入力 ★必須
   ＋ 自由に足せる項目（最大4つ）
   ＋ 画像（最大6枚・1枚ずつ一言コメント）

 ── 【みんなに一言】 ★必須 ─────────
   いちばん下に、大きめの枠で出ます。

 ── そのほか（任意）────────────────
   ・ひとこと（一覧カードに大きく出ます）
   ・X のURL
   ・そのほかのリンク（最大5つ）
   ・カードの色8種 / もよう5種 / ヘッダー画像

■ 自由項目とギャラリーはカテゴリごとに別
   「私について」に足した項目・画像は「私について」の中に、
   「TFT」に足したものは「TFT」の中に出ます。混ざりません。
   画像は1枚ずつコメント欄があり、詳細画面では画像の下に、
   クリックで拡大したときは画像の下に出ます。

■ 必須のあつかい（前の版と同じ）
   ・編集画面の上に「あと 3つ： ふりがな / 意気込み / みんなに一言」
     のように残りが出て、書くたびに減ります。
   ・ぜんぶ埋まるまで「保存して公開」は押せません。
   ・Tactics Tool には「持っていない」チェックがあります。
   ・Tactics Tool は「Riot IDから作る」で自動入力できます。
       Mo10C#819 → https://tactics.tools/player/jp/Mo10C/819

■ 前の版からの変更
   ・「軽く自己紹介！」→【みんなに一言】に変わりました（中身は引きつぎます）
   ・【X】は必須から任意に移しました。
     指定のリストに X が無かったためです。
     必須にもどす場合は言ってください。
   ・自由項目・ギャラリーが1組だったものを、カテゴリごとに分けました。
     前の版で書いた内容は「私について」に引きつがれます。
   ・枚数の上限を変えました
       自由項目 5つ → 4つ（カテゴリごと）
       画像     8枚 → 6枚（カテゴリごと・合計12枚まで）
     ※ 合計サイズの上限（820KB）に収まるようにするためです。
