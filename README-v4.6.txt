=========================================
 v4.6 ― LP集計の直し（2026-09-15）
=========================================

■ 何が起きていたか
LPランキングのページを開くと、その時点で「ログインしたときのランク」が
今日の記録として書き込まれていました。
ログイン時のランクは何日も前のものであることがあるため、

  ・数値そのものが変
  ・グラフの線が飛ぶ・下がる
  ・23:45の自動集計が、あとから開いた人の古い値で上書きされる

という症状が出ていました。
さらに日付が「端末のローカル時刻」で決まっていたため、
海外や時計のずれた端末で見ると日付が1日ずれていました。

■ 直したこと
1) ページを開いてもLPは記録しません。
   実際のLPを書き込むのは
     ・毎日23:45（日本時間）の自動集計
     ・管理コンソールの「全員のLPを今すぐ記録」
   だけになりました。
   ログイン時は「名前・アイコン・Riot ID・ロール」だけを更新します
   （集計の名簿を最新に保つため）。

2) 日付はすべて日本時間で数えるようにしました。
   Worker（23:45の集計）と完全に同じ計算です。

3) グラフの横軸が重ならないようにしました。
   期間が短いときは真ん中の日付を出しません。

4) 集計が動いているかが見えるようにしました。
   ・LPランキングの上に「✅ 最終集計 2026-09-15 23:45」と出ます
   ・2日以上止まっていると警告が出ます（Riot APIキー切れがよくある原因）

5) 管理コンソール →「📈 LP」に
   「おかしな日の記録を消す」を追加しました。
   古い版が書いてしまった変な日の点を、日付を選んで消せます。

■ 差し替えるファイル
   GitHub Pages 側（サイトのフォルダ）
     core.js
     lp.html
     editor.html
     boards.html / home.html / index.html / login.html
     members.html / schedule.html
       ※ この6つは ?v=4.6 のキャッシュ更新だけです

   Cloudflare Worker
     worker.js   （集計した時刻を残すようにしました）

   config.js は入っていません（今の設定をそのまま使ってください）

■ 差し替えたあと
 1. ブラウザで強制リロード（Ctrl/⌘ + Shift + R）
 2. 管理コンソール →「📈 LP」で
      ・「✅ 最終集計 …」が出ているか確認
      ・グラフを見て、明らかにおかしい日があれば
        「おかしな日の記録を消す」で消す
 3. Cloudflare の Cron が
      45 14 * * *   （＝日本時間 23:45）
    になっているか一応確認してください

■ 注意
これまでにたまってしまった「変な値」は自動では消えません。
上の「おかしな日の記録を消す」で1日ずつ消してください。
