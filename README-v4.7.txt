=========================================
 v4.7 ― メンバー紹介（2026-09-15）
=========================================

ログインした人が自分のプロフィールを書いて、
ログインした人みんなが見られるページです。

■ 書ける内容
 【固定の項目（みんな同じ）】
   ・ひとこと（カードに大きく出ます）
   ・じこしょうかい（長文・改行OK）
   ・TFTのこと … TFT歴 / 好きなコンプ / 好きなユニット /
                 プレイスタイル / 目標ランク
   ・ひととなり … 好きなこと・趣味 / よくいる時間帯

 【その人らしさが出るところ】
   ・じゆうらん（最大5つ）
       見出しも中身も自分で決められます。
       「最近ハマってるもの」「好きな配信者」「ここだけの話」など。
   ・ギャラリー（最大8枚）＋ 1枚ずつのひとこと
   ・ヘッダー画像
   ・カードの色（8色）と もよう（5種類）
   ・リンク（X・YouTubeなど 最大5つ）

■ 画像の入れかた（2通り）
   ① ファイルを選ぶ … ブラウザの中で自動的に小さくしてから保存します
        （3200x2100・595KB の写真 → 約29KB のヘッダーに）
   ② URLを貼る    … 容量をまったく使いません
   ※ 上限は 1人あたり 820KB。編集画面の下に「保存サイズ」のメーターが出ます。

■ 公開のしかた
   ・ログインした人は全員見られます
   ・書きかえられるのは本人だけです
   ・管理者は、不適切なものを「非表示」にできます
     （その人のプロフィールを開くと、下にボタンが出ます。中身は消えません）
   ・まだ書いていない人も一覧に出ます（「書いてくれるとうれしい！」の
     カードになります）

■ できること
   ・名前・ひとこと・好きなコンプ・趣味 で検索
   ・ロールでしぼりこみ（生徒 / 先生 / 校長 …）
   ・並べかえ（更新が新しい順 / 名前順 / ランク順 / 記入が多い順）
   ・🎲 だれか見る … ランダムで誰かのプロフィールを開きます
   ・カードを開くと大きく表示。← → で前後の人へ移動できます
   ・ギャラリーの写真はクリックで拡大

■ 保存されるところ（Firestore）
   lboard_profiles/<ユーザーID>     … プロフィール本体（画像を含む）
   lboard_index/profile_cards       … 一覧用の軽い版（サムネだけ）

   ★ 2つに分けている理由
     画像を含む本体は1人あたり数百KBになります。
     一覧を出すたびに全員ぶんを読むと何十MBにもなってしまうので、
     一覧には「名前・ひとこと・色・小さなサムネ」だけを読み、
     くわしく開いたときにだけ その人の本体を読みにいきます。
     （1人あたり 一覧は約8KB、本体は最大820KB）

■ 差し替えるファイル
   core.js
   members.html   ← 新しい中身（今までは「準備中」の画面でした）
   boards.html / editor.html / home.html / index.html /
   login.html / lp.html / schedule.html
     ※ この7つは ?v=4.7 のキャッシュ更新だけです

   Worker（worker.js）の変更はありません。
   config.js も入っていません（今の設定をそのまま使ってください）

■ 差し替えたあと
   1. ブラウザで強制リロード（Ctrl/⌘ + Shift + R）
   2. HOME →「メンバー紹介」を開く
   3. 「✏️ 自分のプロフィールを書く」から書いてみてください
   4. みんなにも書いてもらうよう声をかけると、一覧がにぎやかになります

■ 安全のためにしていること
   ・javascript: などの危ないURLは弾いています
   ・SVG画像は受けつけません（中にスクリプトを書けるため）
   ・他人のIDを指定しても、他人のプロフィールは保存できません
