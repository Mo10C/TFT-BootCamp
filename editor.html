🏠 HOME 🏆 大会一覧

見出し

HOME画面の一番上に出る文字です。

メニュータイル

HOMEに並ぶPOPです。上下で並び替え、「表示」を外すと非表示、「準備中」でグレー＋バッジになります。
ロールを指定すると、そのロールを持つ人にだけ表示されます（管理者には常に表示）。
リンク先は同じフォルダ内のファイル名（例: members.html）か、外部URL

ツール

HOMEの下部に並ぶリンク集です。既存のポータルや他ツールへの導線に。
プレビュー ↗ 保存すると全員のHOMEに反映されます

大会名 default

いま開いているボードの設定です。別のボードを編集するには「大会の管理」から開き直してください。

🚪 公開範囲

ロールを指定すると、そのロールを持つ人だけが入場できます。管理者は常に入場できます。

大会（ボード）一覧

開く＝そのボードの管理に切り替わります。新規作成は大会一覧ページから。
＋ 新しい大会を作る

⚠️ 大会の削除

選手・組卓・順位を含めて完全に削除します。元に戻せません。
削除する前に「データ」タブからJSONバックアップを取ることを強くおすすめします。
確認のため、IDを手で入力してもらう形にしています。

比較の基準日

LPランキングの「基準」列は、ここで指定した日からの増減です。合宿の開始日などを入れてください。
空欄にすると「基準」列は表示されません。

記録

LPはメンバーがログインした日に自動で1点ずつ記録されます（1日1回）。
全員ぶんをその場で取りたいときは下のボタンを使ってください。大会前後や合宿の初日・最終日に押すと、 きれいな比較ができます。
Riot APIで最新ランクを取得してから記録します
Worker に設定した CRON_KEY を入れて実行（毎晩23:45の処理と同じもの）
LPランキングを開く ↗

メンバー

ログインした人が自動で登録されます。名前をタップすると表示名を変更でき、以降は本人が再ログインしても上書きされません（空欄で保存すると解除）。
運営ロールの人は既定で「不参加」です（参加者一覧・組卓・全体順位・LPランキングに出ません）。 大会に出てもらうときは「大会に参加」をONにしてください。

Worker（Riot API / Discord 連携）

ここでの変更はこのブラウザにのみ保存され、config.js より優先されます。動作確認用です。

バックアップ

現在のボードの全データ（メンバー・組卓・結果・公開範囲）を含みます。
